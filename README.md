# SNS 영상 한국어 자막·더빙 도구

## 한국어 더빙

`edge-tts`의 SunHi(여성) 또는 InJoon(남성) 음성으로 한국어 더빙을 만들 수 있습니다. 원음을 교체하거나 원음을 20% 볼륨으로 작게 섞는 방식을 선택할 수 있습니다. 자막 입히기와 더빙을 함께 선택하면 더빙 영상에도 한국어 자막이 포함됩니다. Edge TTS 음성 합성에는 인터넷 연결이 필요합니다.

X/Twitter, YouTube, TikTok, Instagram, Facebook, Reddit, Vimeo, Twitch, Threads 영상 또는 내 컴퓨터의 영상에서 영어 음성을 인식하고 한국어 자막과 더빙 영상을 만드는 무료 로컬 웹앱입니다. 유료 API 키가 필요하지 않습니다.

## 기능

- 지원 SNS의 영상 또는 게시물 URL에서 단일 영상 다운로드(재생목록 제외)
- URL 영상은 빠른 360p(기본), 표준 720p, 원본/최고 화질 중에서 선택
- 로그인이 필요한 영상은 Edge, Chrome, Firefox 브라우저 쿠키를 직접 읽도록 선택 가능(쿠키 파일을 내보내거나 기록하지 않음)
- 로컬 영상 업로드
- 영어 자막과 한국어 자막(SRT) 생성
- 선택적으로 한국어 자막을 영상에 입혀 MP4 생성
- 여성·남성 음성을 선택해 한국어 더빙 MP4 생성
- 원음을 교체하거나 작게 줄여 더빙 아래에 혼합
- AI 처리는 내 컴퓨터에서 수행

## Windows 설치

PowerShell에서 이 폴더로 이동한 다음 실행합니다.

```powershell
Set-ExecutionPolicy -Scope Process Bypass
.\setup.ps1
.\run.ps1
```

브라우저에서 `http://127.0.0.1:7860`이 자동으로 열립니다. 첫 실행 때 Whisper 음성 인식 모델과 영어→한국어 번역 모델을 내려받기 때문에 시간이 걸립니다. 이후에는 다운로드한 모델을 재사용합니다.

## 사용법

1. 지원되는 SNS의 영상·게시물 주소를 입력하거나 영상 파일을 올립니다.
2. 로그인이 필요한 본인 콘텐츠라면 사용 중인 브라우저를 선택합니다.
3. 긴 URL 영상은 빠른 360p를 권장합니다. 720p와 원본 화질은 다운로드 시간과 저장 용량이 크게 늘어납니다.
4. 빠른 처리 또는 높은 정확도 모델을 선택합니다.
5. 필요하면 `한국어 자막을 영상에 입히기`를 선택합니다.
6. 더빙이 필요하면 `한국어 무료 더빙 만들기`와 음성·오디오 방식을 선택합니다.
7. 실행 후 생성된 SRT/MP4 파일을 내려받습니다.

더빙은 Microsoft Edge의 온라인 음성 서비스를 사용하는 `edge-tts` 기반이므로 인터넷 연결이 필요합니다. `원음 교체`는 영어 음성을 한국어 음성으로 바꾸고, `원음을 작게 섞기`는 원래 영상 소리를 약 20%로 낮춰 더빙 아래에 남깁니다.

비공개·연령 제한·로그인이 필요한 게시물은 플랫폼 정책에 따라 다운로드가 실패할 수 있습니다. 본인이 접근 권한을 가진 콘텐츠에만 브라우저 쿠키를 사용하세요. 실패할 때는 브라우저에서 영상을 직접 저장한 뒤 로컬 영상 업로드를 사용하세요. YouTube의 최신 JavaScript 확인 절차를 지원하기 위해 설치 스크립트가 Deno와 `yt-dlp-ejs`도 준비합니다.

## 모델과 성능

- 음성 인식: faster-whisper (`base.en` 또는 `small.en`, CPU INT8)
- 번역: Argos Translate 영어→한국어 오프라인 모델
- 한국어 음성: Edge TTS (`SunHi` 여성, `InJoon` 남성)
- 영상 처리: FFmpeg

CPU만으로 동작하지만 영상 길이와 컴퓨터 성능에 따라 실제 영상 재생 시간보다 오래 걸릴 수 있습니다. 자동 번역은 고유명사, 속어, 배경음이 많은 영상에서 틀릴 수 있으므로 중요한 콘텐츠는 결과를 확인하세요.

## 결과 위치

결과는 `outputs/<작업번호>/`에 보존됩니다. 원본 영상, 영어 SRT, 한국어 SRT, 선택한 경우 자막 포함 MP4와 한국어 더빙 MP4가 들어갑니다.

## 주의

본인이 다운로드·번역할 권한이 있는 콘텐츠에만 사용하세요. 영상의 저작권과 X 이용 조건을 준수할 책임은 사용자에게 있습니다.
